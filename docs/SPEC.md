## 완료

- [x] **A01 · 로컬 한글 단문 연습** · v0.0.1
  - 루프백 실행기에서 한글 단문을 열어 입력 오타와 점수를 확인하고, 결과에서 재시도하거나 메뉴로 돌아간다.
  - Fedora WSL의 Chromium에서 외부 요청을 차단한 배포물과 조합 이벤트를 검증했다. Windows 11 Chrome에서 한글 입력, 제출, Enter 재시도, Esc 메뉴 복귀를 확인했다. 실제 OS 한글 입력기를 쓰는 지원 행렬은 A06에서 검증한다.

## 구현할 작업

- [ ] **A02 · 자리·낱말 연습과 콘텐츠 선택** [바로 다음에 구현해야 함]
  - 두벌식 자리 연습에서 화면 자판에 눌러야 할 물리 키를 안내하고, 키 목록을 끝내면 결과를 보여준다. 낱말·단문을 한글과 영문에서 고를 수 있다.
  - 단문을 제출하면 같은 화면에 직전 문장의 점수를 남기고 다음 문장으로 이어간다. Esc로 돌아가면 선택했던 메뉴 항목에 초점을 돌려준다.
  - 언어와 모드에 맞는 제시문을 로컬에서 읽고, 잘못된 콘텐츠가 메뉴나 세션을 중단시키지 않는지 확인한다.
- [ ] **A03 · 여러 줄 장문 연습** · A01 이후
  - 목록에서 제목과 글자 수를 보고 글을 고른다. 주변 줄과 전체 줄 수를 보여주고, 제출할 때마다 입력 초점을 다음 줄로 옮긴다. 마지막 줄에서 전체 정확도와 분당 글자 수를 보여준다.
- [ ] **A04 · 최근 연습 기록** · A02, A03 이후
  - 완료한 세션을 같은 주소에서 다시 열어 확인하고, 이전 연습과 결과를 비교한다. 중복 저장, 여러 탭 동시 완료, 최대 보존 건수, 저장 실패, 로컬 데이터 초기화를 확인한다.
- [ ] **A05 · 로컬 표시 설정** · A04 이후
  - 글자 크기 설정을 바꾸면 연습 화면에 곧바로 반영되고 다시 열어도 유지된다. 기본값으로 되돌릴 수 있다.
- [ ] **A06 · 세 OS 지원 확인** · A05 이후
  - Windows 11·macOS·Linux의 실제 브라우저와 한글 IME에서 프로젝트 명세의 품질 기준을 확인한다. 재현 가능한 설치·실행 절차와 확인한 조합을 README에 반영한다.
- [ ] **A07 · 시간 제한 타자 도전** · A06 이후
  - 시작 화면에서 제한 시간과 목표를 확인한다. 제한 시간 안에 제시되는 짧은 목표를 해결하고 결과를 확인한다. 시작·중단·재시도가 가능하다. 구체적인 진행 규칙은 이 슬라이스를 시작할 때 명세에 반영한다.
