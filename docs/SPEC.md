# SPEC

현재 버전은 `v0.0.7`이다. 제품의 동작과 기술 결정은 [프로젝트 명세](PROJECT-SPEC.md)를 따른다.

## 상태 표시

- 체크된 항목은 구현을 마치고 완료 조건을 확인한 작업이다.
- 현재 구현 중인 사용자 기능 슬라이스에 [지금 구현중]을 붙인다. 완료 후 체크하고 레이블을 뗀다.
- 선행 작업과 완료 조건이 정해진 다음 한 항목에 [바로 다음에 구현해야 함]을 붙인다.
- 플랫폼 검증의 미확인 항목은 별도의 비차단 후속으로 관리한다. Windows 11 + Chrome의 기본 흐름을 막는 치명적 문제가 재현된 경우에만 현재 개발을 멈춘다.

## 완료

- [x] **A01 · 로컬 한글 단문 연습** · v0.0.1
  - 루프백 실행기에서 한글 단문을 열어 입력 오타와 점수를 확인하고, 결과에서 재시도하거나 메뉴로 돌아간다.
  - Fedora WSL의 Chromium에서 외부 요청을 차단한 배포물과 조합 이벤트를 검증했다. Windows 11 Chrome에서 한글 입력, 제출, Enter 재시도, Esc 메뉴 복귀를 확인했다. 실제 OS 한글 입력기를 쓰는 지원 행렬은 A06에서 검증한다.
- [x] **A02 · 자리·낱말 연습과 콘텐츠 선택** · v0.0.2
  - 화면 자판으로 두벌식 키 위치를 연습하고, 한글·영문 낱말과 단문을 선택한다. 단문 제출 시 직전 점수를 남기고 다음 문장으로 이어간다.
  - 빈 제시문 제외, 위치 정확도, 키보드 메뉴 이동과 초점 복원, 문장 전환을 확인했다.
- [x] **A03 · 여러 줄 장문 연습** · v0.0.3
  - 제목과 글자 수로 글을 고른다. 현재 줄에 초점을 두고, 마지막 줄을 제출하면 전체 결과를 보여준다.
  - 줄 사이 시간을 포함한 합산, 줄 전환, 목록 및 메뉴로 돌아갈 때 초점 복원을 확인했다.
- [x] **A04 · 최근 연습 기록** · v0.0.4
  - 최근 100회 결과를 로컬에 보존하고 모드별로 찾아보거나 지울 수 있다. 결과 화면에는 같은 모드와 언어의 직전 기록을 표시한다.
  - 여러 탭의 동시 완료, 중복 제거, 최대 건수, 손상된 저장값 보존, 쓰기 실패 및 초기화를 확인했다.
- [x] **A05 · 로컬 표시 설정** · v0.0.5
  - 연습 중에 글자 크기를 세 단계로 선택하고 기본값으로 되돌릴 수 있다. 입력 보존, 즉시 반영, 새로고침 이후 유지와 초기화를 확인했다.
- [x] **A07 · 시간 제한 타자 도전** · v0.0.6
  - 30초 동안 한글 낱말을 맞히고 해결한 수를 확인할 수 있다. 시작, 오타 수정, 중단, 만료, 재시도와 메뉴 초점 복원을 확인했다.
- [x] **A08 · 자유 입력 연습장** · v0.0.7
  - 시작 메뉴에서 빈 여러 줄 편집기를 열어 한글·영문 등 원하는 내용을 입력한다. Enter는 줄바꿈이며 일반 편집과 붙여넣기를 허용한다. Esc 또는 ‘메뉴’ 버튼으로 돌아가고 ‘연습장’ 초점을 복원한다. 나간 입력은 저장하지 않아 다시 열면 빈 편집기다.
  - 점수, 결과 화면, 연습 기록을 만들지 않는다. 단위 테스트 12개, 전체 E2E 11개, 빌드를 통과했다. Windows Chrome에서는 메뉴 진입, 두 줄 입력, Esc 복귀·초점 복원, 빈 상태 재진입을 확인했다. 브라우저 제어 도구의 텍스트 입력은 실제 OS IME 확인을 대신하지 않는다.

## 검증 후속 (개발 비차단)

- [ ] **A06 · Windows 11 + Chrome 기준 환경 확인**
  - Windows 호스트에서 Node 26.13.0 / npm 12.2.0으로 엄격한 `npm ci`, `npm run build`, `node serve.mjs`와 루프백 HTTP 200을 확인했다.
  - Chrome에서 한글 단문 입력, 100% 점수, Enter 제출, 다음 문장과 직전 점수, Esc 메뉴 복귀를 확인했다. 입력은 브라우저 제어 도구로 수행해 실제 Microsoft IME 조합을 증명하지 않는다. Playwright의 합성 IME 테스트도 OS 입력기를 구동하지 않는다.
  - 실제 Microsoft IME 조합과 Backspace, Enter 두 번의 구분, 오프라인 새 프로필, 200% 확대를 확인한다. 도구 제어 실패나 미확인만으로 개발을 멈추지 않는다.
  - Chromium·Firefox·WebKit 자동 검증과 Ubuntu Firefox + IBus 한글 두벌식 실기 확인은 보조 근거다. Windows Edge와 macOS Safari 검증은 후속 호환성 작업이다. [A06 Draft PR](https://github.com/SaehwanPark/retro-typing-playground/pull/6)
