# SPEC

현재 버전은 `v0.0.11`이다. 제품의 동작과 기술 결정은 [프로젝트 명세](PROJECT-SPEC.md)를 따른다.

## 상태 표시

- 체크된 항목은 구현을 마치고 완료 조건을 확인한 작업이다.
- 현재 구현 중인 사용자 기능 슬라이스에 [지금 구현중]을 붙인다. 완료 후 체크하고 레이블을 뗀다.
- 선행 작업과 완료 조건이 정해진 다음 한 항목에 [바로 다음에 구현해야 함]을 붙인다.
- 플랫폼 검증의 미확인 항목은 별도의 비차단 후속으로 관리한다. Windows 11 + Chrome의 기본 흐름을 막는 치명적 문제가 재현된 경우에만 현재 개발을 멈춘다.

- [x] **A08 · 자유 입력 연습장** · v0.0.7
  - 시작 메뉴에서 빈 여러 줄 편집기를 열어 한글·영문 등 원하는 내용을 입력한다. Enter는 줄바꿈이며 일반 편집과 붙여넣기를 허용한다. Esc 또는 ‘메뉴’ 버튼으로 돌아가고 ‘연습장’ 초점을 복원한다. 나간 입력은 저장하지 않아 다시 열면 빈 편집기다.
  - 점수, 결과 화면, 연습 기록을 만들지 않는다. 단위 테스트 12개, 전체 E2E 11개, 빌드를 통과했다. Windows Chrome에서는 메뉴 진입, 두 줄 입력, Esc 복귀·초점 복원, 빈 상태 재진입을 확인했다. 브라우저 제어 도구의 텍스트 입력은 실제 OS IME 확인을 대신하지 않는다.
- [x] **A09 · 화면 이미지 저장** · v0.0.8
  - 모든 화면에서 버튼이나 Windows 기준 `Ctrl+S`로 현재 앱 화면을 PNG로 내려받는다. 앱은 저장 요청 전에는 이미지를 만들거나 보존하지 않는다.
  - 저장 이미지는 현재 화면의 입력·점수·설정을 포함한다. 연습장 화면에서 사용자가 저장을 요청하면 자유 입력도 이미지 파일에 포함된다. 이 파일은 앱 기록이나 서버 전송에 추가하지 않는다.
  - 빌드와 전체 검증을 통과했다. Windows Chrome에서 버튼과 `Ctrl+S` 다운로드를 확인했고, 저장된 PNG에 연습장 두 줄 입력이 보이는 것을 확인했다. 실패 안내와 IME 조합 중 단축키 보존을 포함한 E2E 4개도 통과했다. 입력 텍스트는 브라우저 자동화로 넣었으므로 실제 OS IME 검증을 대신하지 않는다.

- [x] **A10 · 색상 테마 선택** · v0.0.9
  - 표시 설정에서 기존 `터미널 야간`과 새 `종이 밝음` 테마를 고르고 모든 화면에 즉시 적용한다. 기본값은 기존 화면을 보존하는 `터미널 야간`이다.
  - 색상 테마는 글자 크기와 분리된 버전형 로컬 설정으로 저장한다. 새로고침 뒤 유지하고, 초기화는 색상만 되돌린다. 기존 크기 설정과 연습 입력은 보존한다. 잘못된 저장값은 기본 테마로 보여주되 자동으로 덮어쓰지 않는다.
  - PNG 저장 배경도 현재 테마를 따른다. 오타는 색뿐 아니라 기존 밑줄 표시로도 구분한다.
  - `npm run verify` 통과: Vitest 5개 파일 12개 테스트, 프로덕션 빌드, Playwright E2E 19개. E2E에서 즉시 적용·새로고침 보존·독립 초기화·손상 및 쓰기 거부 처리·PNG 배경을 확인했다. A10 당시에는 Windows 11 Chrome 수동 확인을 수행하지 못했지만, 2026-11-18 후속 사용자 감사에서 테마 동작을 확인했다.
  - 참조 앱의 색상 설정 항목을 반영하되 정확한 색상 팔레트 복제는 가정하지 않는다. A11에서 연습 글꼴을 추가했으며 효과음은 후속 범위다.

- [x] **A11 · 연습 글꼴 선택** · v0.0.10
  - 표시 설정에서 `고딕`과 `명조`를 고른다. 기본 고딕은 기존 모양을 유지하며, 명조는 `Batang`, `Times New Roman`, 브라우저 기본 serif 순서로 사용한다.
  - 제시문, 입력창, 장문 문맥, 자유 입력 편집기, 도전 낱말에 즉시 적용한다. 메뉴·키보드 도식·점수 텍스트는 바꾸지 않는다. 글꼴 변경은 입력·진행·점수를 보존한다.
  - 별도 버전형 로컬 설정 키에 저장하고 새로고침 뒤 유지한다. 초기화는 글꼴만 되돌리며 글자 크기·색상 테마에는 영향을 주지 않는다. 손상된 값은 기본값으로 보이고 자동 덮어쓰지 않으며, 저장 실패는 현재 탭에 적용하고 안내한다.
  - 화면 저장 PNG도 선택한 글꼴을 사용한다. 외부 폰트나 CDN 없이 시스템 글꼴만 사용해 오프라인 범위를 유지한다.
  - 가정: 참조 앱의 글꼴 설정 항목은 확인했지만 글꼴 목록은 재현하지 않는다. `고딕`은 기존 시스템 UI 계열을 유지하고 `명조`만 추가한다. 효과음은 후속 범위다.
  - `npm run verify` 통과: Vitest 5개 파일 12개 테스트, 프로덕션 빌드, Playwright E2E 23개. 즉시 적용·새로고침 보존·독립 초기화·입력과 다른 설정 보존·손상 및 쓰기 실패 처리·적용 범위·메뉴 글꼴 유지·기존 PNG 검증을 통과했다. A11 구현 당시 수동 설정 확인은 하지 않았으나, 2026-11-18 후속 사용자 감사에서 글꼴 설정 동작을 확인했다.
- [x] **A12 · 언어별 환경설정과 인터페이스** · v0.0.11
  - 시작 메뉴의 환경설정을 방향키·Enter로 열고, 활성 화면에서는 환경설정 바로가기로 연다. 돌아오면 이전 화면과 입력 상태를 유지한다. 시작 메뉴로 복귀할 때는 환경설정 항목에 초점을 둔다.
  - 인터페이스 언어와 연습 언어는 독립적으로 선택하고 기본값은 모두 한국어다. 영어 UI는 모든 화면 안내와 접근 가능한 이름을 번역한다. 영어 연습에서는 영문 자료와 공통 연습장·기록·설정만 메뉴에 남긴다.
  - 언어 설정은 연습/결과 화면에서 변경할 수 없고 홈 메뉴에서 바꾼다. 크기·테마·글꼴·효과음은 연습 중에도 바꿔 현재 입력과 진행을 유지한다.
  - 글꼴 선택은 한국어와 영어별로 따로 저장한다. 기존 공통 글꼴 저장값은 기존 동작을 보존하기 위해 두 언어에 모두 이전한다. 영어 명조는 Georgia 계열, 한글 명조는 Batang 계열을 사용한다.
  - 완료 효과음은 기본 끔이다. 단문·낱말·장문 줄·자리 연습 단위를 제출하거나 도전 낱말을 맞힐 때 한 번 재생하고, 글자 입력 중에는 재생하지 않는다. 오디오 재생 실패는 연습을 막지 않는다.
  - `npm run verify` 통과: Vitest 5개 파일 12개 테스트, 프로덕션 빌드, Playwright E2E 26개. 설정의 키보드 진입·초점 복귀, 언어 필터·보존, 구버전 글꼴 이전과 언어별 글꼴, 연습 중 화면 설정 변경 뒤 입력 보존, 완료 때만 효과음 재생을 확인했다. 새 설정 UI의 실제 Windows Chrome 수동 점검은 후속이며 기존 IME 처리 코드는 변경하지 않았다.

## 진행 중

- [ ] **A13 · 언어별 타자 속도 단위** · v0.0.12 [지금 구현중]
  - 환경설정에서 한국어와 영어의 속도 표시 단위를 각각 고른다. 기본은 한국어 cpm(분당 타수), 영어 wpm(분당 단어 수)이다.
  - 진행 중 점수, 결과, 기록 목록, 결과 비교가 연습 언어의 선택 단위를 사용한다. wpm은 기존 원시 cpm을 5로 나누어 표시한다.
  - 기록에는 원시 점수를 그대로 보존한다. A12 설정 저장값은 기본 단위를 채워 새 형식으로 읽는다.
- [ ] **A14 · 한글 단문 끝맺기** · v0.0.13 [바로 다음에 구현해야 함]
  - 한국어 단문 연습 자료에서 문장 끝의 문장부호를 제거한다. 본문 안의 문장부호와 영문 자료는 바꾸지 않는다.

## 호환성 후속 (개발 비차단)

- Windows Edge와 macOS Safari는 현재 수용 기준에 포함하지 않는다. 필요가 생기면 별도 호환성 슬라이스로 검증한다.
