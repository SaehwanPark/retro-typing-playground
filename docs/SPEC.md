# SPEC

현재 버전은 `v0.0.5`이다. 제품의 동작과 기술 결정은 [프로젝트 명세](PROJECT-SPEC.md)를 따른다.

## 상태 표시

- 체크된 항목은 구현을 마치고 완료 조건을 확인한 작업이다.
- 첫 작업 커밋부터 [지금 구현중]을 활성 항목에 붙인다. 완료 후 체크하고 레이블을 뗀다.
- 선행 작업과 완료 조건이 정해진 다음 한 항목에 [바로 다음에 구현해야 함]을 붙인다.

## 완료

- [x] **A01 · 로컬 한글 단문 연습** · v0.0.1
  - 루프백 실행기에서 한글 단문을 열어 입력 오타와 점수를 확인하고, 결과에서 재시도하거나 메뉴로 돌아간다.
  - Fedora WSL의 Chromium에서 외부 요청을 차단한 배포물과 조합 이벤트를 검증했다. Windows 11 Chrome에서 한글 입력, 제출, Enter 재시도, Esc 메뉴 복귀를 확인했다. 실제 OS 한글 입력기를 쓰는 지원 행렬은 A06에서 검증한다.
- [x] **A02 · 자리·낱말 연습과 콘텐츠 선택** · v0.0.2
  - 화면 자판으로 두벌식 키 위치를 연습하고, 한글·영문 낱말과 단문을 선택한다. 단문 제출 시 직전 점수를 남기고 다음 문장으로 이어간다.
  - 빈 제시문 제외, 위치 정확도, 키보드 메뉴 이동과 초점 복원, 문장 전환을 확인했다.
- [x] **A03 · 여러 줄 장문 연습** · v0.0.3
  - 제목과 글자 수로 글을 고른다. 현재 줄에 초점을 두고, 마지막 줄을 제출하면 전체 결과를 보여준다.
  - 줄 사이 시간을 포함한 합산, 줄 전환, 목록 및 메뉴로 돌아갈 때 초점 복원을 확인했다.
- [x] **A04 · 최근 연습 기록** · v0.0.4
  - 최근 100회 결과를 로컬에 보존하고 모드별로 찾아보거나 지울 수 있다. 결과 화면에는 같은 모드와 언어의 직전 기록을 표시한다.
  - 여러 탭의 동시 완료, 중복 제거, 최대 건수, 손상된 저장값 보존, 쓰기 실패 및 초기화를 확인했다.
- [x] **A05 · 로컬 표시 설정** · v0.0.5
  - 연습 중에 글자 크기를 세 단계로 선택하고 기본값으로 되돌릴 수 있다. 입력 보존, 즉시 반영, 새로고침 이후 유지와 초기화를 확인했다.
