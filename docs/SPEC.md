# SPEC

현재 버전은 `v0.0.0`이다. 제품의 동작과 기술 결정은 [프로젝트 명세](PROJECT-SPEC.md)를 따른다.

## 상태 표시

- 체크된 항목은 구현을 마치고 완료 조건을 확인한 작업이다.
- 첫 작업 커밋부터 [지금 구현중]을 활성 항목에 붙인다. 완료 후 체크하고 레이블을 뗀다.
- 선행 작업과 완료 조건이 정해진 다음 한 항목에 [바로 다음에 구현해야 함]을 붙인다.

## 완료

완료된 기능이 없다.

## 진행 중

진행 중인 구현이 없다.

## 구현할 작업

- [ ] **A01 · 로컬 한글 단문 연습** [지금 구현중]
  - Vite·React·TypeScript와 npm으로 앱을 만들고 지원하는 Node.js LTS 버전, 빌드·검증 스크립트, 로컬 실행기를 문서화한다.
  - 직접 작성한 단문 한 편으로 메뉴 → 입력 → 결과 → 재시도와 메뉴 복귀가 된다. 방향키·Enter·Esc로 이동한다. 한글이 확정되면 화면의 점수가 갱신되며, 조합 확정에 쓴 Enter는 세션을 제출하지 않는다. 오타·수정·초과 글자와 결과 계산을 확인한다.
  - 배포물로 고정 루프백 주소를 열어 외부 연결 없이 처음부터 한 판을 마친다. 이 슬라이스에서 사용한 OS·브라우저·IME와 검증 결과를 PR에 남긴다.
- [ ] **A02 · 자리·낱말 연습과 콘텐츠 선택** · A01 이후
  - 두벌식 자리 연습에서 화면 자판에 눌러야 할 물리 키를 안내하고, 키 목록을 끝내면 결과를 보여준다. 낱말·단문을 한글과 영문에서 고를 수 있다.
  - 언어와 모드에 맞는 제시문을 로컬에서 읽고, 잘못된 콘텐츠가 메뉴나 세션을 중단시키지 않는지 확인한다.
- [ ] **A03 · 여러 줄 장문 연습** · A01 이후
  - 각 줄을 제출하면 다음 줄을 제시한다. 마지막 줄까지 입력하면 전체의 정확도와 분당 글자 수를 보여준다.
- [ ] **A04 · 최근 연습 기록** · A02, A03 이후
  - 완료한 세션을 같은 주소에서 다시 열어 확인하고, 이전 연습과 결과를 비교한다. 중복 저장, 여러 탭 동시 완료, 최대 보존 건수, 저장 실패, 로컬 데이터 초기화를 확인한다.
- [ ] **A05 · 로컬 표시 설정** · A04 이후
  - 글자 크기 설정을 바꾸면 연습 화면에 곧바로 반영되고 다시 열어도 유지된다. 기본값으로 되돌릴 수 있다.
- [ ] **A06 · 세 OS 지원 확인** · A05 이후
  - Windows 11·macOS·Linux의 실제 브라우저와 한글 IME에서 프로젝트 명세의 품질 기준을 확인한다. 재현 가능한 설치·실행 절차와 확인한 조합을 README에 반영한다.
- [ ] **A07 · 시간 제한 타자 도전** · A06 이후
  - 제한 시간 안에 제시되는 짧은 목표를 해결하고 결과를 확인한다. 시작·중단·재시도가 가능하다. 구체적인 진행 규칙은 이 슬라이스를 시작할 때 명세에 반영한다.
