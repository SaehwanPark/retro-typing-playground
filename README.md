# Retro Typing Playground

한메타자교실에서 느꼈던 타자 연습의 재미를 오늘날 브라우저로 옮기는 프로젝트입니다. 키보드로 연습을 고르고, 한글 제시문을 입력한 뒤 결과를 보고 다시 도전하는 흐름을 만듭니다.

현재 개발 기준 환경은 Windows 11 + Chrome입니다. Windows Edge와 macOS의 호환성 확인은 후속 범위이며, Linux Firefox와 IBus 한글 두벌식은 보조 환경으로 확인했습니다. 브라우저와 운영체제의 한글 입력기를 사용하고, 배포물을 받아 로컬에서 실행하면 인터넷 연결 없이 연습할 수 있도록 설계했습니다.

## 현재 상태

`v0.0.14`에서 두벌식 자리 연습, 한글·영문 낱말 및 연속 단문, 한글 장문, 30초 낱말 도전, 제시문 없는 연습장을 사용할 수 있습니다. 한글 단문은 문장 끝 문장부호 없이 연습합니다. 낱말·단문·장문 줄·도전 낱말은 입력을 마친 뒤 Enter나 Space로 제출할 수 있고, 그 전의 Space는 입력 중인 공백으로 남습니다. 한글 IME 조합을 Space로 끝내면 조합 글자를 확정한 뒤 남은 제시문에는 공백 하나를 넣고, 입력이 끝났으면 같은 Space로 제출합니다. 연습장은 여러 줄 자유 입력을 지원하며 나가면 입력 내용을 앱에 저장하지 않습니다. 점수와 연습 기록도 만들지 않습니다. 화면 저장 버튼이나 `Ctrl+S`로 현재 화면을 PNG로 내려받으며, 연습장에 보이는 입력도 이미지에 포함됩니다. 같은 브라우저에서 최근 100회 결과를 관리합니다. 시작 메뉴의 환경설정에서 한국어·영어 인터페이스와 연습 언어를 고르고, 글자 크기, `터미널 야간`·`종이 밝음` 테마, 언어별 `고딕`·`명조` 글꼴, 언어별 타자 속도 단위(cpm/wpm), 완료 효과음을 설정할 수 있습니다. 한국어는 cpm, 영어는 wpm이 기본이며, 기록은 원시 cpm으로 저장합니다. 완료 효과음은 기본 꺼짐이며 입력 글자마다 소리 나지 않습니다.

Windows 11 호스트의 설치·빌드·루프백 실행은 확인했습니다. 2026-11-18 사용자 수동 감사에서 Windows Chrome의 실제 한국어 IME 조합과 Enter 처리, 오프라인 새 프로필, 200% 확대, 색상 테마와 연습 글꼴을 확인했습니다. A15에서 추가한 조합 중 Space 동작은 합성 IME E2E로 확인했으며 실제 입력기 수동 감사는 아직입니다. Windows Edge와 macOS Safari는 후속 호환성 범위입니다. OS와 브라우저별 확인 내용은 [플랫폼 검증표](docs/PLATFORM-VERIFICATION.md)를 참고하세요.

## 실행하기

Node.js LTS 22.12.0 이상이 필요합니다. 저장소에서 빌드한 뒤 실행합니다.

```sh
npm ci
npm run build
node serve.mjs
```

브라우저에서 [로컬 타자 연습](http://127.0.0.1:41793/)을 엽니다. 빌드한 앱을 옮길 때는 `dist/`와 `serve.mjs`를 같은 디렉터리에 두고 `node serve.mjs`를 실행하세요. Node.js와 두 파일 경로만 준비되면 오프라인에서 연습할 수 있습니다.

개발 중에는 `npm run dev`를 사용합니다. 전체 검증은 `npx playwright install chromium`을 실행한 뒤 `npm run verify`로 진행합니다.
