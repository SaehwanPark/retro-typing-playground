# Retro Typing Playground

한메타자교실에서 느꼈던 타자 연습의 재미를 오늘날 브라우저로 옮기는 프로젝트입니다. 키보드로 연습을 고르고, 한글 제시문을 입력한 뒤 결과를 보고 다시 도전하는 흐름을 만듭니다.

현재 개발 기준 환경은 Windows 11 + Chrome입니다. A17에서 macOS Tahoe + Chrome 157의 한국어 IME 공백 처리도 실제 입력기로 확인했으며, Windows Edge와 macOS Safari의 일반 호환성 확인은 후속 범위입니다. Linux Firefox와 IBus 한글 두벌식은 보조 환경으로 확인했습니다. 브라우저와 운영체제의 한글 입력기를 사용하고, 배포물을 받아 로컬에서 실행하면 인터넷 연결 없이 연습할 수 있도록 설계했습니다.

## 현재 상태

`v0.0.19`에서 두벌식 자리 연습, 한글·영문 낱말과 `한 줄`, 문학·비문학·기술·생활·서브컬쳐 장르의 `짧은 글`·`긴 글`, 30초 낱말 도전, 제시문 없는 연습장을 사용할 수 있습니다. 한 줄은 문장 끝 문장부호 없이 연습합니다. 짧은 글과 긴 글은 5줄을 한 묶음으로 보여주며, 완료한 줄과 현재 줄·다음 줄을 함께 보면서 한 줄씩 제출합니다. 연습 자료와 도전 낱말은 `src/content/assets/`의 JSON 애셋에서 읽습니다. 직접 작성한 원문과 함께 위키문헌·위키백과(CC BY-SA 4.0), 법령(저작권법 제7조)처럼 사용 조건이 분명한 자료를 쓰며, 복제한 자료는 글 고르기 목록에 저자·출처·라이선스를 표시합니다. 낱말·한 줄·글의 각 줄·도전 낱말은 입력을 마친 뒤 Enter나 Space로 제출할 수 있고, 그 전의 Space는 입력 중인 공백으로 남습니다. 한글 IME 조합을 Space로 끝내면 조합 글자를 확정한 뒤 남은 제시문에는 공백 하나를 넣고, 입력이 끝났으면 같은 Space로 제출합니다. macOS Tahoe + Chrome 157의 기본 2-Set Korean 입력기로 공백 하나 삽입과 단일 단계 이동을 확인했습니다. 연습 화면의 환경설정과 화면 저장 버튼은 같은 위쪽 기준선에 정렬됩니다. 연습장은 여러 줄 자유 입력을 지원하며 나가면 입력 내용을 앱에 저장하지 않습니다. 점수와 연습 기록도 만들지 않습니다. 화면 저장 버튼이나 `Ctrl+S`로 현재 화면을 PNG로 내려받으며, 연습장에 보이는 입력도 이미지에 포함됩니다. 같은 브라우저에서 최근 100회 결과를 관리합니다. 시작 메뉴의 환경설정에서 한국어·영어 인터페이스와 연습 언어를 고르고, 글자 크기, `터미널 야간`·`종이 밝음` 테마, 언어별 `고딕`·`명조` 글꼴, 언어별 타자 속도 단위(cpm/wpm), 완료 효과음을 설정할 수 있습니다. 설정은 ↑/↓로 항목 사이를 이동하고 ←/→ 또는 Enter/Space로 값을 바꾸며, 초기화 동작도 Enter/Space로 실행합니다. 다른 탭이나 창에서 돌아오면 마지막으로 사용한 앱 컨트롤에 포커스가 복구됩니다. 한국어 CPM은 완성 글자가 아니라 남아 있는 입력의 두벌식 타수로 계산합니다(`한`은 3타, 쌍자음은 1타, 이중모음·겹받침은 2타, 공백·문장부호는 각각 1타). 오타·초과 입력도 타수에는 포함하고 정확도는 글자 기준으로 별도 계산합니다. 영어 WPM은 이전 계산을 유지하며, 기존 한국어 기록은 복원할 수 없는 옛 속도값을 숨깁니다. 완료 효과음은 기본 꺼짐이며 입력 글자마다 소리 나지 않습니다.

Windows 11 호스트의 설치·빌드·루프백 실행은 확인했습니다. 2026-11-18 사용자 수동 감사에서 Windows Chrome의 실제 한국어 IME 조합과 Enter 처리, 오프라인 새 프로필, 200% 확대, 색상 테마와 연습 글꼴을 확인했습니다. 같은 날 macOS Tahoe + Chrome 157에서 실제 2-Set Korean IME로 A17의 공백 하나 삽입과 Space 단일 단계 이동을 확인했습니다. Windows Chrome의 A17 이후 수동 회귀 확인은 하지 않았으며, Windows Edge와 macOS Safari의 일반 호환성은 후속 범위입니다. OS와 브라우저별 확인 내용은 [플랫폼 검증표](docs/PLATFORM-VERIFICATION.md)를 참고하세요.

## 실행하기

Node.js LTS 22.12.0 이상이 필요합니다. 저장소에서 빌드한 뒤 실행합니다.

```sh
npm ci
npm run build
node serve.mjs
```

브라우저에서 [로컬 타자 연습](http://127.0.0.1:41793/)을 엽니다. 빌드한 앱을 옮길 때는 `dist/`와 `serve.mjs`를 같은 디렉터리에 두고 `node serve.mjs`를 실행하세요. Node.js와 두 파일 경로만 준비되면 오프라인에서 연습할 수 있습니다.

개발 중에는 `npm run dev`를 사용합니다. 전체 검증은 `npx playwright install chromium`을 실행한 뒤 `npm run verify`로 진행합니다.
